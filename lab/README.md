# CellBit 算法演示台

教师主导演示，不含学生作业或提交功能。所有案例都可离线运行。

## 启动

在网站根目录运行 `python -m http.server 4173 --bind 127.0.0.1`，打开 `http://127.0.0.1:4173/lab/`。
也可以直接打开 `lab/index.html`（全屏按钮取决于浏览器支持）。

每个模块从“从头演示”开始，按“下一步”推进预设；右方向键也可推进。自动播放每步间隔5秒，可随时暂停。操作参数会暂停播放。切换页面会重置参数。

## 边界

- 这是可复算的教学算法，不运行神经网络，不伪装模型精度。
- 不包含葡萄原视频、学生信息、客户资料、账号或API密钥。
- 不采集访客信息，无上传与联网API。
- 公开内容只有通用解释和原始论文链接；不搬运第三方整篇论文或视频。
- 演示页面随主页发布在 `https://cellbit.cn/lab/`，网站首页提供相对路径入口。

## 测试

`node lab/test.cjs` 检查核心数值算法。浏览器另检查八个演示、下一步、重置、滑块、全屏和源码链接。
