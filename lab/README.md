# 通用视频分析教师演示台

入口为 index.html，核心内容可离线运行。包含公开OpenCV样例预计算结果、卷积、IoU和NMS教学示例。
没有项目研究数据、标注、实验成绩、个人账号或学生信息。

## 使用

直接打开 index.html，或在网站根目录启动本地静态服务器。教师按左侧顺序讲解，方向键切换，空格播放与暂停。

## 公开发布

演示页面发布于 `https://cellbit.cn/lab/`。`assets` 内为 OpenCV `vtest` 公开样例及衍生结果，保留来源与文件哈希；站点所有者已于 2026-10-27 确认这些素材可公开发布。未复制用户提供的讲座图示或论文插图到网站目录。

## 方法边界

HOG行人框、帧差、MOG2、LK光流为实际OpenCV结果。卷积、IoU和NMS为教学数值。YOLO、SAM 2、ByteTrack、SlowFast为论文方法介绍，不宣称本课运行了这些模型。
