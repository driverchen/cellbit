# CellBit Homepage

CellBit 的静态主页，聚焦计算机视觉、第一视角智能与视频理解。

未公开的页面规划与内容边界记录在 `ITERATION.md`，不会被首页引用。

## 本地预览

```powershell
python -m http.server 4173 --directory D:\project\iron\cellbit_homepage
```

打开 `http://127.0.0.1:4173/`。

## 发布

站点为纯静态 HTML/CSS/JavaScript，可直接部署到 GitHub Pages。`CNAME` 已配置为 `cellbit.cn`。
